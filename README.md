## Starta backend
1. `cd backend`
2. `pip install -r requirements.txt`
3. `python app.py`

## Starta frontend
*Frontend is a React CDN application served via FastAPI.*
1. Navigate to `http://127.0.0.1:8000/user/login`

## Endpoints
- POST /tasks/ (Create)
- GET /tasks/ (Read All)
- GET /tasks/{id} (Read One)
- PUT /tasks/{id} (Update)
- DELETE /tasks/{id} (Delete)
